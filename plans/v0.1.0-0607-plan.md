# AI Daily Digest v0.1.0 — Content Expansion + Morning Audio Broadcast

> **For agentic workers:** Use `superpowers:executing-plans` to implement this plan
> task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. (Per repo owner's
> preference, do NOT use subagent-driven-development for this work.)

**Goal:** Broaden what the daily digest captures (hardware, robotics/physical-AI,
industry/deals/policy, NVIDIA, official-source-first) and add a Marin-voiced
3–8 min audio brief posted to Slack each morning.

**Architecture:** Two surfaces change. (1) `setup.py`'s `SYSTEM_PROMPT` is rewritten
to expand sources/sections/rules and to instruct the agent to emit a third output — a
spoken "broadcast script" — via a new `send_audio_broadcast` custom tool. (2) `run.py`
gains an orchestrator-side handler that turns that script into an MP3 (OpenAI
`gpt-4o-mini-tts`, voice `marin`, chunked to respect the 4096-char cap) and uploads it
to Slack via the 3-step external-upload flow. The TTS key and Slack bot token stay
orchestrator-side, exactly like the existing webhook.

**Tech Stack:** Python 3.12 (stdlib `urllib` only — no new deps), Anthropic Managed
Agents beta SDK (existing), OpenAI `/v1/audio/speech`, Slack Web API
(`files.getUploadURLExternal` / `files.completeUploadExternal`), GitHub Actions cron.

## Design decisions

**Resolved (from brainstorming):**
- **Format unchanged** — curated sections, `• headline — why it matters — URL`, `—`
  separators, `•` bullets, fixed section order. We only change *what is captured*.
- **Sections (new fixed order):** Anthropic · OpenAI · Google AI · **NVIDIA** · Meta ·
  xAI / Grok · **Hardware & Chips** · **Robotics & Physical AI** · Open-source models &
  agents · Developer Tools & Vibe Coding · **Industry, Deals & Policy** · Trending GitHub.
  (Bold = new.)
- **Entity-first routing** — if the announcing company has its own section, the item
  goes there even if it's a chip/robot/deal (topic as sub-clause). Topic sections are
  for entities *without* their own section (e.g. NVIDIA's chip → NVIDIA; Intel's chip →
  Hardware & Chips).
- **Official-source-first** — every bullet's URL must be the official/primary source
  when one exists; third-party only supplements or fills a gap, phrased "reportedly";
  unconfirmed-rumor-only items are dropped.
- **Collapse empty sections** — omit any section with no news (no "No updates today.").
  Bias to fewer, higher-signal bullets; keep ≤4/section.
- **China = supplement** — Chinese labs (DeepSeek, Qwen, Kimi, Zhipu, Doubao, MiniMax)
  live under "Open-source models & agents", never as the headline focus. US-tech focus.
- **Look-back = strict 24h**, deduped against yesterday's note (already readable from the
  mounted vault).
- **Audio:** Marin voice, 3–8 min spoken brief, delivered as a Slack audio file (MVP).
- **TTS:** OpenAI `gpt-4o-mini-tts`, steered via an `instructions` tone string.

**Decisions confirmed with repo owner:**
1. **Audio is a *soft* requirement.** If the note commit + text Slack post both
   succeeded, a TTS/upload failure logs a warning but the run still exits 0. Rationale:
   the written digest is the core deliverable; don't turn CI red (and risk dup reruns)
   over a TTS hiccup. The note + text Slack remain *hard* requirements (exit 1 on
   failure), unchanged.
2. **Text stays on the existing incoming webhook; audio uses the bot token.** The proven
   `SLACK_WEBHOOK_URL` text path is untouched. The MP3 is uploaded with `SLACK_BOT_TOKEN`
   to `SLACK_CHANNEL_ID`. **Requirement:** `SLACK_CHANNEL_ID` must be the same channel the
   webhook posts to, and the bot must be invited to it, so text + audio land together.
   (Future improvement: unify on the bot token and thread the audio under the text post.)
3. **MP3 stitching = ffmpeg remux for ≥2 chunks, byte-join fallback.** Single-chunk
   scripts (≤4000 chars — the common case) ship as-is. Multi-chunk scripts are concatenated
   with `ffmpeg -f concat -c copy` (preinstalled on `ubuntu-latest`) into a clean container
   that seeks correctly and plays in full across Slack's player and podcast apps; if ffmpeg
   is absent (e.g. local Windows dev) it falls back to raw byte-join. (Refines the earlier
   "naive byte-concat" call after adversarial review flagged that raw MP3 concatenation can
   truncate or mis-seek in some players — a real risk for the flagship audio feature.)
4. **Agent gets recreated.** Changing `SYSTEM_PROMPT` + adding a tool changes the
   canonical agent hash, so `setup.py` will archive the old agent and create a new one
   with a **new `AGENT_ID`** — which must be re-saved as a GitHub secret (Task 6). The
   environment is unchanged (`ENVIRONMENT_ID` stays).
5. **Schedule moved earlier to absorb GitHub's cron delay.** GitHub Actions `schedule:`
   cron is best-effort — documented delays are commonly 45 min–2 h+ and occasionally ~4 h
   (GitHub staff acknowledged worsening drift in 2026), worst near the top of the hour.
   The `timezone:` key IS honored (IANA TZ shipped 2026-03-19, DST-aware), so `13 7 * * *`
   correctly targeted 7:13 am ET; the delay is what pushed actual runs to ~9–11 am. Fix
   (option A): move the cron to **`43 4 * * *` (4:43 am ET)** so even a 2–3 h delay lands
   the digest by ~7–8 am, keeping the off-top-of-hour minute. Still best-effort (a dropped
   run = no digest that day; the Slack post is the heartbeat). External dispatch via
   `workflow_dispatch` + an external scheduler is the documented upgrade if punctuality
   becomes critical — not implemented now.

```python
def _split_for_tts(text, max_chars=TTS_MAX_CHARS):
    """Split text into <=max_chars chunks on sentence boundaries.

    Falls back to hard-splitting any single sentence longer than max_chars so
    no chunk ever exceeds the OpenAI /v1/audio/speech 4096-char input cap.
    """
    text = (text or "").strip()
    if not text:
        return []
    if len(text) <= max_chars:
        return [text]
    sentences = re.findall(r"[^.!?\n]+[.!?]?\s*", text)
    chunks, cur = [], ""
    for s in sentences:
        if len(s) > max_chars:
            if cur:
                chunks.append(cur)
                cur = ""
            for i in range(0, len(s), max_chars):
                chunks.append(s[i:i + max_chars])
            continue
        if len(cur) + len(s) <= max_chars:
            cur += s
        else:
            if cur:
                chunks.append(cur)
            cur = s
    if cur.strip():
        chunks.append(cur)
    return [c.strip() for c in chunks if c.strip()]
```

```python
def _tts_one(api_key, text):
    """Synthesize one <=4096-char chunk. Returns (ok, mp3_bytes_or_None, detail)."""
    payload = json.dumps(
        {
            "model": TTS_MODEL,
            "input": text,
            "voice": TTS_VOICE,
            "instructions": TTS_INSTRUCTIONS,
            "response_format": "mp3",
        }
    ).encode("utf-8")
    headers = {
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json",
        "User-Agent": USER_AGENT,
    }
    delays = [0, 2.0, 4.0]
    last = "unknown"
    for i, delay in enumerate(delays):
        if delay:
            time.sleep(delay)
        req = urllib.request.Request(
            OPENAI_TTS_URL, data=payload, headers=headers, method="POST"
        )
        try:
            with urllib.request.urlopen(req, timeout=HTTP_TTS_TIMEOUT) as r:
                if 200 <= r.status < 300:
                    return True, r.read(), f"status={r.status}"
                last = f"http {r.status}"
        except urllib.error.HTTPError as e:
            body = e.read().decode("utf-8", "replace") if e.fp else ""
            last = f"http {e.code}: {body[:200]}"
        except Exception as e:  # URLError, timeout, etc.
            last = f"{type(e).__name__}: {e}"
        log.warning("TTS attempt %d/%d failed: %s", i + 1, len(delays), last)
    return False, None, last


def _concat_mp3(parts):
    """Concatenate MP3 segments into one playable file. Returns (mp3_bytes, method).

    Single segment -> returned as-is. Multiple segments -> ffmpeg stream-copy remux
    (preinstalled on ubuntu-latest) for a clean container that seeks correctly and
    doesn't truncate in Slack's player. If ffmpeg is unavailable (e.g. local Windows
    dev) or fails, fall back to raw byte-join.
    """
    if len(parts) == 1:
        return parts[0], "single"
    ffmpeg = shutil.which("ffmpeg")
    if ffmpeg:
        with tempfile.TemporaryDirectory() as td:
            seg_paths = []
            for i, p in enumerate(parts):
                sp = os.path.join(td, f"seg{i:03d}.mp3")
                with open(sp, "wb") as f:
                    f.write(p)
                seg_paths.append(sp)
            list_path = os.path.join(td, "list.txt")
            with open(list_path, "w", encoding="utf-8") as f:
                for sp in seg_paths:
                    # ffmpeg concat demuxer: escape backslashes for Windows paths.
                    f.write("file '%s'\n" % sp.replace("\\", "\\\\"))
            out_path = os.path.join(td, "out.mp3")
            proc = subprocess.run(
                [ffmpeg, "-y", "-f", "concat", "-safe", "0", "-i", list_path,
                 "-c", "copy", out_path],
                capture_output=True,
            )
            if proc.returncode == 0 and os.path.exists(out_path):
                with open(out_path, "rb") as f:
                    return f.read(), "ffmpeg"
            log.warning(
                "ffmpeg concat failed (rc=%s): %s; falling back to byte-join",
                proc.returncode,
                proc.stderr.decode("utf-8", "replace")[:200],
            )
    return b"".join(parts), "byte-join"


def synthesize_tts(api_key, script):
    """Turn a spoken script into MP3 bytes (chunked + concatenated).

    Returns (ok, mp3_bytes_or_None, detail).
    """
    chunks = _split_for_tts(script)
    if not chunks:
        return False, None, "empty script"
    parts = []
    for idx, chunk in enumerate(chunks):
        ok, mp3, detail = _tts_one(api_key, chunk)
        if not ok:
            return False, None, f"chunk {idx + 1}/{len(chunks)}: {detail}"
        parts.append(mp3)
    audio, method = _concat_mp3(parts)
    return True, audio, f"{len(chunks)} chunk(s), concat={method}"
```

```python
def _slack_api_post(method, bot_token, form):
    """POST a form-encoded Slack Web API call. Returns parsed JSON, raises on ok=false."""
    url = f"{SLACK_API}/{method}"
    data = urllib.parse.urlencode(form).encode("utf-8")
    headers = {
        "Authorization": f"Bearer {bot_token}",
        "Content-Type": "application/x-www-form-urlencoded",
        "User-Agent": USER_AGENT,
    }
    req = urllib.request.Request(url, data=data, headers=headers, method="POST")
    with urllib.request.urlopen(req, timeout=HTTP_WRITE_TIMEOUT) as r:
        body = json.loads(r.read().decode("utf-8"))
    if not body.get("ok"):
        raise RuntimeError(f"slack {method} error: {body.get('error')}")
    return body


def slack_upload_audio(bot_token, channel_id, mp3_bytes, filename, title, comment):
    """Upload an MP3 to a Slack channel via the external-upload flow.

    Returns (ok, detail). Three steps: reserve URL -> POST bytes -> complete+share.
    """
    try:
        info = _slack_api_post(
            "files.getUploadURLExternal",
            bot_token,
            {"filename": filename, "length": str(len(mp3_bytes))},
        )
        upload_url = info["upload_url"]
        file_id = info["file_id"]

        put = urllib.request.Request(
            upload_url,
            data=mp3_bytes,
            headers={"Content-Type": "audio/mpeg", "User-Agent": USER_AGENT},
            method="POST",
        )
        with urllib.request.urlopen(put, timeout=HTTP_WRITE_TIMEOUT) as r:
            if not (200 <= r.status < 300):
                return False, f"upload POST status {r.status}"

        _slack_api_post(
            "files.completeUploadExternal",
            bot_token,
            {
                "files": json.dumps([{"id": file_id, "title": title}]),
                "channel_id": channel_id,
                "initial_comment": comment,
            },
        )
        return True, f"file_id={file_id}"
    except Exception as e:
        return False, f"{type(e).__name__}: {e}"


def handle_send_audio_broadcast(openai_key, bot_token, channel_id, date_str, tool_input):
    """Synthesize the spoken script and upload it to Slack. Returns (result, is_error).

    Audio is a SOFT feature: if any audio secret is unset, return a soft error
    (is_error=True) instead of raising, so the run still succeeds on the note + text.
    """
    missing = [
        name
        for name, val in (
            ("OPENAI_API_KEY", openai_key),
            ("SLACK_BOT_TOKEN", bot_token),
            ("SLACK_CHANNEL_ID", channel_id),
        )
        if not val
    ]
    if missing:
        return {"sent": False, "error": f"audio disabled: missing {', '.join(missing)}"}, True

    script = tool_input.get("script")
    if not isinstance(script, str) or not script.strip():
        return {"sent": False, "error": "script must be a non-empty string"}, True

    ok, mp3, detail = synthesize_tts(openai_key, script)
    if not ok:
        return {"sent": False, "error": f"tts failed: {detail}"}, True

    filename = f"ai-daily-digest-{date_str}.mp3"
    title = f"AI Daily Digest — {date_str}"
    comment = f":headphones: Your AI morning brief for {date_str}"
    up_ok, up_detail = slack_upload_audio(
        bot_token, channel_id, mp3, filename, title, comment
    )
    if not up_ok:
        return {"sent": False, "error": f"slack upload failed: {up_detail}"}, True

    log.info(
        "audio broadcast uploaded: %s (%d bytes, %s)", filename, len(mp3), detail
    )
    return {"sent": True, "bytes": len(mp3)}, False
```
